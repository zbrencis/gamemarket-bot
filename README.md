GameMarket Bot is a plug & play Discord marketplace bot designed for any game or trading community.

This project is currently in early beta and open for testing and feedback.

## Features
- Trade posts
- Offer management
- Private trade tickets
- Reputation system
- Disputes & moderation tools
- Auto setup per server

## Notes
- Environment variables are not included
- This project is open source under the MIT license
- Early beta – APIs and behavior may change
